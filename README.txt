KIDDO WORLD — Versi awal
========================

Cara menjalankan:
1. Ekstrak folder KIDDO-WORLD dari ZIP.
2. Buka index.html dengan browser.
3. Game dapat dimainkan tanpa server.

Catatan offline:
- Semua kode utama berada di file lokal.
- Tidak ada font, API, atau aset dari internet yang diperlukan.
- Progres bintang disimpan menggunakan localStorage browser.
- Salin gambar referensi KUYO ke assets/characters/kuyo-reference.jpg agar gambar maskot tampil di halaman utama.

Isi versi awal:
- Menu utama dan tiga dunia.
- 5 soal contoh untuk setiap dunia.
- Sistem jawaban, umpan balik ramah, skor bintang, dan penyimpanan progres.

Ini adalah prototipe awal. Tahap berikutnya dapat menambahkan ilustrasi latar orisinal, karakter KUYO yang dipotong menjadi sprite, suara lokal, level tambahan, profil anak, dan sertifikat.
